# Changelog

## 0.1.0 (unreleased)

- First version for the Fairwire family, forked from lodestar-core 0.1.0 (including the Windows fixes of 18 November 2026).
- Freight, parcel and X12 modules removed; IT export catalogue (firewalls, identity, cloud bills, backups, device management, service desks).
- Added personal-data masking (pii.js) in every result, error and approval request, with a per-installation pseudonym key.
- Added IT helpers (it.js) and the agent builder (agent.js) with accepted exceptions and the standard draft note.
- Report titles and sections for the IT agents in nine languages; IT column names in eight languages.
- Contract tests use a fixed pseudonym key so two runs compare equal.
